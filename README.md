# homebrew-tap

Homebrew tap for [ElliottH](https://github.com/ElliottH)'s apps.

```sh
brew tap ElliottH/tap
```

## Apps

| Cask | Repo |
|---|---|
| [`hypr`](Casks/hypr.rb) | [ElliottH/hypr](https://github.com/ElliottH/hypr) |
| [`prattle`](Casks/prattle.rb) | [ElliottH/prattle](https://github.com/ElliottH/prattle) |

```sh
brew install --cask ElliottH/tap/hypr
brew install --cask ElliottH/tap/prattle
```
